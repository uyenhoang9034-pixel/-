# 🐰 Bể Ảnh Quote của Usagi Múp Rụp

Thư mục này dùng để lưu trữ các hình ảnh quote (ảnh trích dẫn, ảnh thơ, ảnh meme) được thiết kế sẵn.

### 📌 Hướng dẫn sử dụng:
1. Bạn có thể tải (upload) trực tiếp các file ảnh vào thư mục này trên GitHub.
2. Định dạng ảnh được hỗ trợ: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`.
3. Khi người dùng gõ `quote` trên Discord, bot sẽ tự động bốc ngẫu nhiên từ cả **bể quote chữ** (`src/data/quotes.txt`) và **bể ảnh quote** trong thư mục này để gửi kèm khung Embed siêu xinh xắn!
